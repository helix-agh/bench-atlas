# CEC 2022

The twelve functions of the CEC 2022 competition on single-objective bound
constrained numerical optimization: basic functions F1-F5, hybrid
functions F6-F8 and composition functions F9-F12, taken from IOH.

```python
from bench_atlas.benchmarks import cec2022

cec2022(dimensions=[10, 20])  # 24 problems
```

The suite is defined only for d = 10 and 20, with one shift and rotation per
function and dimension, so the instance is always 1. Ids follow IOH's numbering,
1000 + F: `cec2022_f1008_i1_d10`.

!!! warning "F3, F5 and F9 are not the competition's functions"

    For these three, the official competition code differs from its technical
    report, and IOH follows the report: F3 (Schaffer) is scaled by 0.5/100,
    F5 (Levy) by 5.12/100, and the second component of F9 is not rotated.
    The other nine match the official C code, against which they are tested.

!!! note "Precision floor"

    After mapping to $[0, 1]^d$, $f(x_\text{opt}) - f_\text{opt}$ is up to
    1.5e-4 (F8, d = 10), so the CEC target of 1e-8 is not reachable there.
