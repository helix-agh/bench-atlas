# BBOB and MA-BBOB

## BBOB

The 24 noiseless functions of the COCO **B**lack-**B**ox **O**ptimization
**B**enchmarking suite, the de facto standard for
continuous black-box optimization. They are grouped into five classes:

| Group | Functions |
|---|---|
| Separable | f1-f5 |
| Low or moderate conditioning | f6-f9 |
| High conditioning, unimodal | f10-f14 |
| Multimodal, adequate global structure | f15-f19 |
| Multimodal, weak global structure | f20-f24 |

Instances are random shifts, rotations and offsets of the same function,
generated by IOH.

```python
from bench_atlas.suites import bbob

bbob(dimensions=[2, 5, 10], instances=range(1, 6))  # 24 x 3 x 5 = 360 problems
```

!!! check "Verified"

    `from_ioh` on BBOB is bitwise identical to raw IOH at the mapped points.

## MA-BBOB

**M**any-**A**ffine BBOB builds new functions as affine
combinations of BBOB functions, with random weights, instances and a new optimum
location; it extends the affine recombination of Dietrich and Mersmann. IOH derives everything from the instance number, so
`ma_bbob_f0_i7_d5` is fully reproducible and bench-atlas samples nothing.

```python
from bench_atlas.suites import ma_bbob

ma_bbob(dimensions=[5], instances=range(1, 101))  # 100 functions
```

!!! info "Function number 0"

    IOH reports `problem_id = 0` for every MA-BBOB problem, so all ids read
    `ma_bbob_f0_i{instance}_d{d}`.
